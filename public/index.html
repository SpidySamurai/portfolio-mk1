My path asFrontEnd Developer

I'm from the beautiful city of Mérida, Yucatán. I'm 24 and I have a passion for web development. My biggest aspiration is to change the technological education in Mexico by raising competitive people.

I started learning programming in 2017, when I was 19 years old. I learned the basics of structural paradigms with C++ and OOP with Java, and then I started learning web technologies like HTML, CSS, and JavaScript in 2020.

In November 2021, I started my first job as a web developer, giving maintenance to a React app, which was a dashboard for clients and administrators that received data for water measurement and interpreted it to generate various features.

In January 2022, I started in another job as a web developer, redesigning their web sites, which were e-commerce, giving code solutions to specific problems, making content, and doing some SEO optimization.

I believe in “Never stop learning”, which is why I am constantly learning and improving my technological skills to deliver and prepare the best of my self on each project.
